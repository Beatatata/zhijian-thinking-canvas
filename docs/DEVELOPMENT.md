# 开发指南

## 开始

安装 Node.js 22 或更新稳定版本，在仓库根目录执行 `npm ci`、`npm run dev`。不需要后端、账号、API Key 或 Sites 绑定。构建执行 `npm run build`，结果在 dist。首次运行看到通用教学示例。

版本：1.0.0 · 2026.10.7；制作人 TATALAB。来源与许可见 ../ATTRIBUTIONS.md 和 ../LICENSE。

## 架构与数据流

- model.ts：Project / Card / Edge 数据、布局、复制、移动、教学示例和备份 validate。
- App.tsx：画布手势、历史撤销、选择、导航和工作台切换；先理解 commit 与内联编辑分组，再修改状态。
- InlineCard / PlanningCard / ImageCard / FocusEditor：原位编辑、专注编辑与内容尺寸测量。
- RichTextEditor / rich-text-schema：Tiptap 格式化编辑与 Markdown 解析；外层正文仅用 ReactMarkdown 阅读渲染，不挂载编辑器；双击卡片进入专注编辑。正文链接保持原生跳转，点击不得触发正文编辑或卡片重复跳转。Card.body 保持字符串，旧备份不迁移。不要在挂载或只读切换时触发正文保存；格式化输入、退出、撤销及重新打开应保持一致。当前仅覆盖常用 Markdown/GFM，不承诺任意 HTML 或第三方 Markdown 插件的无损编辑。
- storage.ts：IndexedDB 工作台、回收站与配置。永久删除仅接受已确认且仍在回收站的 ID 快照，整批预检后事务删除项目与同步设置，留下不含内容的 purged ID 标记，阻止延迟保存复活；不得删除活跃或已恢复工作台。测试使用 fake-indexeddb，不对真实个人数据执行不可逆验证。
- connections / snapping / arrange：连线、吸附、分布几何。
- appearance / icons / style.css：配色、Tabler 图标和外观。样式存在历史叠加，修改前定位最终生效规则。
- export / thought-export：Markdown、CSV、附件、离线阅读文档和完整备份。
- folder-sync / mirror：页面内单向增量文件镜像、稳定路径、哈希冲突保护和目录权限。

分栏与其内容在 DOM 中是兄弟卡片。子项位置由 layout 派生，分栏拖动时应保持子项归属，提升显示层级而不是隐藏或搬走内容。

## 修改后的检查

执行 `npm test`、`npm run build`。视觉修改在浏览器检查；不要仅凭构建成功判断交互正确。使用独立测试地址或教学示例，不操作用户个人工作台。

回归路径：中文输入法／回车；清单排序／完成状态；分栏拖动／折叠／撑高；画板拖入分栏；复制／撤销／恢复备份；连线弯曲／标题遮挡；外观浅深色；导出各卡片类型；同步外部修改保护；工作台回收站、永久删除确认取消、JSON 导入为独立工作台。

新增卡片类型时检查创建默认值、旧数据 validate、原位与专注编辑、布局、复制、撤销、归属、导出与测试。字段可选时明确默认行为，不能依靠渲染过程修改持久数据。

## 发布边界

开发代码可以公开，个人 IndexedDB 数据不能自动成为源码。测试截图与备份只用合成数据。`.openai/hosting.json` 是制作人的私有发布绑定；开源包排除它，不复用项目 ID。贡献者不用安装 Sites 插件即可运行或构建。

当前没有云端多用户协作、双向 Obsidian 同步、后台同步、表格公式或移动端体验承诺。提出这些功能前先讨论数据边界和兼容方案。

## 下一步

优先考虑：拆分画布手势与工作台状态；减少叠加样式；键盘与屏幕阅读器支持；大画板性能；表格粘贴；导出阅读顺序；文件夹同步授权状态说明。每次只推进一个可验证的改进。
